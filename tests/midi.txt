# MIDI in over the TRS jack ("uart" = raw bytes on the jack, parsed as firmware/src/midi_uart.c does) and MIDI out over USB.
#   .\fm1.ps1 host groovedeck tests/midi.txt > build\host\midi-trace.txt ; python tests\check_midi.py build\host\midi-trace.txt
# A  running status: one status byte, three notes: 36 38 40 = pads 1 3 5 (KICK, CLAP, O.HAT) at velocity 100, 80, 127
100 uart 90 24 64 26 50 28 7F
# B  note offs with clock bytes inside the messages: nothing sounds
300 uart 80 24 00 F8 26 00 F8 28 00
# C  a real-time byte between the data bytes of a note on (note 42 = pad 7, RIM, velocity 100); Start / Stop / Clock are dropped
500 uart 90 2A F8 64
600 uart F8 FA F8 FC
# D  a SysEx on the jack is ignored (its data bytes look like a note on); the note after it plays (43 = COWBL, velocity 80)
700 uart F0 7D 24 64 F7 90 2B 50
# E  note on with velocity 0 is a note off: no hit
900 uart 90 24 00
# F  any channel: note 51 on channel 10 = pad 16 (ZAP), note 45 on channel 4 = pad 10 (CNG L)
1000 uart 99 33 70 93 2D 40
# G  General MIDI drum notes outside 36..51: 35 kick, 63 hi conga, 75 claves, 82 shaker, 57 crash, 59 ride, 56 cowbell, 61 low bongo,
#    58 vibraslap; 65 (timbale) and 20 map to nothing
1200 uart 90 23 50 3F 50 4B 50 52 50 39 50 3B 50 38 50 3D 50 3A 50 41 50 14 50
# H  program change: 0-7 pattern, 8-11 kit, 12 and up ignored
1500 uart C0 03
1600 uart C0 09
1700 uart C0 0C
1800 uart C0 00
# I  CC 120 and 123 silence the drums, other CCs do nothing
1900 uart 90 24 64 90 2B 64
1950 uart B0 78 00 B0 07 64
2000 uart B0 7B 00
# J  a panel pad (key 1 = KICK) goes out over USB: note 36 on channel 10, then its note off
2200 keys 0x1
2300 keys 0
# K  note repeat (ARP held) rolls an external note at its own velocity, and stops with the note off; nothing of it goes out
2600 btn 10 1500
2700 uart 90 28 50
3500 uart 80 28 00
# L  note repeat on a panel pad (key 2 = SNARE) goes out
4200 btn 10 1200
4300 keys 0x2
5000 keys 0
# M  the sequencer's steps go out with their level; a MIDI hit while it runs sounds but is not echoed; CC 123 leaves it running
6000 btn 12
6500 uart 90 2F 63
7000 uart B0 7B 00
8200 btn 12
# N  live record from MIDI: REC armed, the played note lands in the pattern and the sequencer plays it in the next bar
8400 btn 13
8500 btn 12
9050 uart 90 2B 7F
9150 uart 80 2B 00
11500 end
